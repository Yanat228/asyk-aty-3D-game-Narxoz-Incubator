# Асық Ату — Цифровая 3D-версия

Современная браузерная адаптация традиционной казахской игры **асық ату** (выбивание асыков).

> «Смотри, теперь в асық можно сыграть и так!»

## Для кого

- Для тех, кто помнит дворовую игру из детства
- Для нового поколения, которое хочет познакомиться с казахской традицией
- Для студентов и участников Narxoz Incubator

## Правила (адаптированные для браузера)

1. **Прицеливание и бросок**  
   Потяни **сақа** (большой жёлтый асык) назад мышкой или пальцем.  
   Чем дальше потянешь — тем сильнее бросок. Работает и на десктопе, и на мобильных.

2. **Цель**  
   Выбить асыки **за золотую круговую границу** поля.

3. **Очки**  
   Каждый выбитый асык = 1 очко.  
   Очки за один и тот же асык **не начисляются повторно**.

4. **Победа**  
   Набери нужное количество очков за ограниченное число бросков.  
   Звёзды зависят от того, насколько экономно ты использовал попытки:
   - ★★★ — почти идеально
   - ★★ — хорошо
   - ★ — уровень пройден

5. **Уровни**  
   6 уровней с разными расстановками.  
   Следующий уровень открывается после получения первой звезды на текущем.

### Авторские дополнения
- 3D-модели асыков (процедурные, вдохновлённые реальной формой косточки)
- Казахские орнаменты (ою) вокруг поля
- Мем «SpongeBob is Proud to be KAZAKH» с анимацией вращения на весь экран при каждом выбитом асыке
- **Магазин скинов** — покупай скины сақа за тенге (звёзды) или тестовый «донат»
- Обучение при первом запуске + подсказки после промаха
- Сохранение прогресса, звёзд, монет и скинов в `localStorage`
- Адаптивное управление (мышь + touch)

## Технологии

| Слой | Технология |
|------|------------|
| Рендер | Three.js (WebGL, 3D) |
| Физика | Matter.js (2D top-down, синхронизирована с 3D) |
| Сборка | Чистый ES-модули + CDN (без сборщика) |
| Хостинг | Любой static (GitHub Pages, Netlify, Vercel…) |

Физический движок с нуля не писался — используется Matter.js.  
3D-сцена и модели — собственные.

## Как запустить локально

```bash
# Просто открой index.html через любой static-сервер
npx serve .
# или
python3 -m http.server 8080
```

Затем открой `http://localhost:8080`.

## Деплой

1. Залей папку на GitHub
2. Включи GitHub Pages (Settings → Pages → Deploy from main)
3. Или задеплой на Netlify/Vercel drag-and-drop

Ссылка на рабочий проект должна открываться с любого устройства.

## Известные ограничения

- Физика 2D (top-down), визуал 3D — это осознанный компромисс для стабильности и приятного геймплея
- Нет мультиплеера и аккаунтов (уровень «Сильный»+)
- Звуки минимальные (Web Audio API)

## Аккаунт и облако (Supabase)

1. Создай проект на https://supabase.com
2. В SQL Editor выполни файл `supabase-schema.sql`
3. В `src/config.js` вставь `supabaseUrl` и `supabaseAnonKey`
4. В Authentication включи Email provider

Без ключей работает **локальный режим**: регистрация/вход на этом устройстве, рекорды и история сохраняются в браузере.
